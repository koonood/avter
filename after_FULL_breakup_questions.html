Choose the platform where your messages live. We'll show you how to export them and what to upload.

WhatsApp Android · iPhone · WhatsApp Web

Android

  1. Open the conversation in WhatsApp.
  2. Tap ⋮ → More → Export chat.
  3. Choose Without media for a smaller export.
  4. Save or send the exported file to your computer.

iPhone

  1. Open the conversation in WhatsApp.
  2. Tap the contact or group name at the top.
  3. Choose Export Chat.
  4. Choose Without Media and save the ZIP.
Upload: .txt or .zip
WhatsApp Web and Desktop are useful for viewing messages, but the native export is done from your phone.
Telegram Windows · macOS · Linux
+

Telegram Desktop

  1. Install and open Telegram Desktop.
  2. Open the chat and use ⋮ → Export chat history.
  3. For a wider export, open Settings → Advanced → Export Telegram Data.
  4. Select Machine-readable JSON when available.
Upload: .json or .zip
Telegram's desktop app provides the most practical native export workflow.

The point
You don't get another chat summary. You get the story of the relationship.

Instead of asking an AI a single question about a conversation, you give it the entire history. The system can compare different periods, identify changes and show you the evidence behind each observation.

You don't have to live together.

Long-distance relationship? Different cities? See each other only on weekends? The analysis works from the communication patterns that actually exist in your history.

You don't need to message every day.

Even if some periods contain only occasional messages, those messages still form part of the timeline. Sparse periods can be compared with other periods — with the report making clear when the available evidence is limited.

FAQ

Questions you might have.

Do we have to have lived together? +

No. Living together is not required. The analysis is based on your communication history, not on whether you shared an apartment, lived in different cities or had a long-distance relationship. The system looks at the patterns present in the messages themselves.

What if we didn't text very often? +

That's okay. The system does not simply count messages and decide what a relationship was like. It can work with periods of frequent communication and periods with fewer messages. Sparse periods are still part of the timeline, although conclusions are presented with lower confidence when there is not enough evidence.

Can it tell when someone stopped loving me? +

It cannot know another person's private feelings with certainty. What it can do is identify when observable communication patterns changed — for example, less initiation, longer response gaps, fewer shared plans or different conflict-recovery patterns. The report separates those observations from interpretation.

What if we used several messengers? +

That's exactly where the full version becomes more interesting. Conversations from WhatsApp, Telegram, Instagram and other sources can be normalized into one timeline, so the analysis is not limited to whichever app happened to be used most recently.

Does it only look at how many messages each person sent? +

No. Message volume is only one signal. A useful analysis can also compare response times, conversation length, initiation, gaps, recurring topics, conflict patterns, repair attempts, future-oriented language and how those patterns change over time.

Will I get the actual messages behind a conclusion? +

That's the goal. Important findings should be traceable back to the underlying period and selected source messages, so you can see why the system identified a particular pattern instead of simply receiving a black-box AI verdict.

This prototype demonstrates the product experience. A production version would process the uploaded export with a secure backend, preserve evidence links to source messages, and clearly distinguish observed patterns from interpretations. It should not claim to know another person's private feelings from text alone.
