# After — исправленная сборка (патч анализа паттернов)

## Что изменено
- AI-выборка больше не ограничивается 20 сообщениями на месяц: стандарт — 80, настраивается через `AFTER_AI_EVIDENCE_PER_MONTH`.
- При выборе доказательств сохраняются окна вокруг маркерных сообщений (контекст до/после), чтобы видеть начало конфликта, ответ, эскалацию и попытку восстановления.
- Добавлена равномерная временная выборка, чтобы модель видела не только эмоционально насыщенные фрагменты.
- В инструкции модели явно добавлено разделение отдельных инцидентов, поиск повторяющихся циклов, траектории серьёзных проблем и контрпримеров.
- В отчёте указывается размер полного архива и объём сообщений, реально использованных AI-слоем.

## Установка
1. Сделай резервную копию текущих `main.py` и `index.html`.
2. Замени их файлами из архива.
3. Установи зависимости проекта как раньше.
4. Создай `.env` на основе `.env.example` и добавь собственный `OPENAI_API_KEY`.
5. Запусти сервер прежней командой запуска.

## Важно
Это патч слоя отбора контекста и инструкции анализа, а не обещание безошибочной психологической оценки. Детальные выводы должны опираться на даты, контекст, несколько независимых эпизодов и контрпримеры.


## Новые разделы анализа

- **Предполагаемые языки любви:** отдельно для обоих участников — вероятный основной и дополнительный язык, наблюдаемые сигналы, уверенность и сравнение совпадений/расхождений. Это гипотеза по переписке, не психологический тест; при недостатке данных система должна прямо указывать неопределённость.
- **Рекомендации на будущее:** какие качества и действия искать в партнёре, зелёные флаги, ранние тревожные сигналы, что обсуждать в начале отношений, вопросы на первый месяц и собственные зоны роста. Рекомендации должны учитывать обе стороны и не сводиться к обвинению одного человека.

## Расширение анализа (новая версия)

В финальную JSON-схему, промпт, HTML-отчёт и PDF добавлены:
- **Карта эмоциональных потребностей** обоих участников: вероятные потребности, выраженные просьбы, что помогало, возможные чувствительные темы и уровень уверенности.
- **Профиль совместимости по измерениям**, без единого фальшиво точного балла: коммуникация, границы, поддержка, восстановление после ссор, ритм жизни и планы — только если есть данные.
- **Разбор циклов конфликтов**: отдельные даты эпизодов, триггер, реакция обоих, эскалация/деэскалация, результат примирения, последнее наблюдаемое состояние и контрпримеры.
- **Переводчик конфликтов**: осторожная интерпретация того, что каждый мог пытаться сказать, где они разминулись и как выразить мысль яснее без обвинения.
- **Альтернативные сценарии** — условные гипотезы, не обещание, что отношения можно было спасти.
- **План дальнейших действий** с двумя ветками: если человек рассматривает восстановление отношений и если двигается дальше; план первых 30 дней новых отношений и собственные навыки для практики.
- **Расширенная PDF-глава** с языками любви, потребностями, совместимостью, конфликтными циклами и рекомендациями.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
pip install -r requirements.txt
cp .env.example .env
# добавь OPENAI_API_KEY в .env
uvicorn main:app --reload
```

Открой `http://127.0.0.1:8000`. Для production не используй `--reload` и настрой секреты/доступ отдельно.

## Проверки и ограничения

Проверены компиляция Python, структура обязательных полей JSON-схемы и синтаксис JavaScript в HTML. Это не заменяет полный end-to-end прогон с действующим API-ключом на конкретном архиве. Новые психологические блоки — гипотезы по переписке; если данных мало, система должна показывать неопределённость. Совместимость не сводится к рейтингу личности.
